# Learn Playwright Batch 2X

A structured learning repository for **Playwright test automation**, starting with **JavaScript fundamentals** and progressing into Playwright-specific topics.

## Prerequisites

- [Node.js](https://nodejs.org/) (v16 or later)

## Chapters

| Chapter | Topic | Files |
|---------|-------|-------|
| 01 | Basics | Hello world, variables, environment setup, loops & functions |
| 02 | JavaScript Concepts | Variable declaration and reassignment (`var`, `let`) |
| 03 | Identifier & Literals | Identifier rules, casing conventions, comments |
| 04 | JavaScript Variables | var/let/const, functions, scoping, hoisting (var/function/let), let/const comparison |

## Getting Started

```bash
# Run any file with Node.js
node Chapter_01_Basics/01_Basics.js
```
